# Roadmap

The phases below are product targets, not guaranteed delivery dates.

| Phase | Focus | Demonstrable milestone |
| --- | --- | --- |
| 01 — Foundation | Brand, intent schema, route model, website | Public repository + synthetic route comparison |
| 02 — Shadow Run MVP | Quote normalization and simulation | Repeatable comparison across at least two supported routes |
| 03 — Live integrations | Venue / data adapters and developer API | Real quotes with provenance and timestamped reports |
| 04 — Agent routing | Agent SDK and constrained execution | Agents request routes programmatically under policy limits |
| 05 — $PICUS utility | Holder eligibility on supported PICUS services | Published discount rules backed by measured unit economics |
