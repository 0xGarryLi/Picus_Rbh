Test alternative agent workflows against the same job. Make efficiency measurable, reproducible and accountable.

THE MECHANISM

THE SECOND PATH
IS THE PRODUCT.

01 / INSTRUMENT

Observe baseline.

Capture action graphs, model usage, time, tool costs and output constraints. No private prompts are published by default.

02 / GENERATE

Build alternatives.

Propose a constrained alternate tool and model execution path while preserving job requirements.

03 / VERIFY

Compare fairly.

Run acceptance checks and compare cost, latency and output quality before recommending a route.

What actually gets compared?

A PICUS comparison is useful only when both candidate executions operate on comparable data, meet the same task objective, and pass an acceptance test. A lower API bill is not a win if the result is wrong.

What makes it hard?

Non-deterministic model outputs, stateful tools, external API variance, privacy constraints, and the actual overhead of running a second route. Shadow execution has a real cost, so PICUS must show net savings rather than merely lower cost in the alternative path.

Research hypotheses

Meaningful optimizations may come from tool-call consolidation, model routing, reusable intermediate results, step elimination and data freshness checks. Every gain must be measured against additional shadow-run compute and the risk of altered outcomes.

QUALITY FIRST

NO QUALITY.
NO SAVINGS CLAIM.

The goal is not to find a cheap execution. The goal is to find a cheaper valid execution.
